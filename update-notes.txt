Quick App Test follow-up and Wi-Fi Direct usability repair. The latest Quick App Test is now persisted privately and can be exported as QuietLink-quick-app-test.txt from Developer tools during or after a call; the normal diagnostic log export also embeds the latest Quick App Test. The in-call test uses a custom fixed-footer dialog so RUN AGAIN, SAVE .TXT, COPY and CLOSE stay visible on small phones. Multi-phone diagnostics now log the installed app version at startup. Logs from the reported direct-connect attempt showed the host Wi-Fi radio was off while the joiner was correctly searching; Wi-Fi Direct does not need a router but Android still requires the Wi-Fi radio on. When that state is detected, the call screen now shows a one-tap TURN WI-FI ON FOR DIRECT action that opens Android's Wi-Fi panel while the existing P2P retry loop continues. Core QL5, LAN, Wi-Fi Direct discovery/connect logic, media framing, and v0.3.64 Quick App Test evaluator rules are otherwise unchanged.
