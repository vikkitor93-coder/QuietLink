Older-Android updater compatibility: fixes another false signature_mismatch when the installed QuietLink already reports the pinned v2 signer but PackageManager parses the downloaded rotated APK through the deprecated legacy signatures API. Android documents that this API returns the oldest signer after certificate rotation. QuietLink now accepts only the exact pinned state: installed current signer=v2 with both pinned certificates in history, archive legacy signer=the pinned original signer; Android's installer still enforces the authenticated old→v2 lineage. v0.3.51 rotation lab is unchanged.
